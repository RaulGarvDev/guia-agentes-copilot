# Laboratorio

## Objetivo
Crear una feature de estado de pedido sin romper legacy.

1. Completa `spec.md`.
2. Selecciona planner y genera plan.
3. Aprueba o corrige.
4. Ejecuta implementer.
5. Activa skill Maven para backend.
6. Ejecuta reviewer y security-reviewer.
7. Guarda trazas en `run-log-template.md`.
