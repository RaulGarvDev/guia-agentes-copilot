# Observabilidad y trazas

Registra por ejecución:
- fecha/hora;
- harness y versión;
- agente seleccionado;
- skill activada;
- tools/MCP invocados;
- archivos cambiados;
- comandos y códigos de salida;
- aprobaciones humanas;
- coste/tokens si el harness lo expone;
- veredicto del revisor.

Nunca registres prompts completos si contienen secretos, código sensible o datos personales. Redacta tokens, cabeceras, cadenas JDBC y payloads.
