# Ejemplos
- `bad-vs-good.md`: transformación comentada.
- `.github/agents/`: perfiles completos por rol, incluido el coordinador de autoría de personalizaciones.
- `.github/skills/`: skills de diseño de agentes, skills, hooks y elección de harness.
- `hooks/copilot/`: configuración Copilot v1 y script/test didácticos. El hook no está activo; lee [`docs/06-hooks.md`](../docs/06-hooks.md) antes de copiarlo a `.github/hooks/`.
- `templates/`: punto de partida para crear agentes propios.
