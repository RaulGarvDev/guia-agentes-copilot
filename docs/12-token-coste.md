# Tokens y coste

## Mantén siempre activo
- reglas críticas de seguridad;
- stack/versiones;
- límites legacy;
- comandos canónicos cortos.

## Carga bajo demanda
- manuales extensos;
- checklist Sonar;
- procedimientos Maven;
- referencias Oracle;
- ejemplos grandes.

## Métricas
Longitud del contexto base, skills activadas por tarea, llamadas a tools, reintentos, tasa de aceptación y tiempo hasta resultado aprobado. No existe una equivalencia universal entre tokens y coste: depende de plan, modelo y harness.
